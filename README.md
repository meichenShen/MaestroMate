# MaestroMate

X Program 古典音乐探索网站项目。拟围绕同一作品，连接音乐家对话、音乐小剧场和音乐侦探。

当前为第一阶段研究初稿，版本日期为 **2026-10-28**。本版已获准上传，研究判断仍需后续用户与原型验证。

先阅读[第一阶段研究总结](Research%20Analysis/phase-1-research-overview.md)，再按需要查看五项并列研究：

| 研究方向 | 内容 |
|---|---|
| [竞品研究](Research%20Analysis/competitor%20analysis.md) | 核心网站、功能比较及项目定位 |
| [文献研究](Research%20Analysis/literature-review.md) | 互动、视觉与角色引导的证据和边界 |
| [用户与需求分析](Research%20Analysis/target-users-and-scenarios.md) | 候选用户、场景及首版需求 |
| [技术与系统方案](Research%20Analysis/technical-feasibility.md) | 技术路线、共享内容与初步架构 |
| [版权与伦理研究](Research%20Analysis/ethics-and-copyright.md) | 素材许可、内容可信度及研究数据 |

听赏图的详细方法核查保留为[文献附录](Research%20Analysis/appendix/listening-maps-evidence.md)。访谈、原型实测和学习效果实验尚未开展，目标年龄仍待定。
